# Lúa Casanova

### Abogada en Vigo · Derecho civil y laboral

Este repositorio contiene el sitio web profesional de **Lúa Casanova Gómez**, abogada en Vigo. El proyecto traduce una práctica jurídica cercana y rigurosa a una experiencia digital sencilla, clara y accesible.

El sitio está pensado para que cada persona pueda entender mejor su situación, conocer las áreas de trabajo y dar el primer paso para solicitar orientación jurídica.

## El sitio

- Presenta los servicios de derecho laboral y derecho civil.
- Explica el enfoque profesional y la forma de trabajo de Lúa Casanova.
- Incluye recomendaciones de clientes y páginas de información legal.
- Ofrece un canal de contacto protegido para consultas iniciales.
- Está diseñado para una navegación fluida desde móvil, tableta y escritorio.

## Construido con

El sitio se ha desarrollado con **Python**, **Flask** y plantillas **Jinja**, con HTML, CSS y JavaScript propios. El formulario de contacto utiliza validación en servidor, protección CSRF y limitación de solicitudes; las consultas se gestionan mediante Formspree.

## Proyecto

El código refleja la versión pública del sitio web y su identidad digital. Los datos de configuración, credenciales y servicios externos se mantienen fuera del repositorio.
